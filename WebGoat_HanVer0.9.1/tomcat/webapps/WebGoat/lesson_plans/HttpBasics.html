강의 제목: Http 기본

강의 주제 및 개념:

브라우저와 웹 어플리케이션 사이의 데이터의 전송에 대한 이해를 위한 기본에 대한 수업입니다.

클라이언트 요청:

HTTP는 어떻게 동작하는가:

모든 HTTP 트랜젝션들은 같은 일반적인 구조을 가집니다. 각 클라이언트의 요청과 서버의 응답은 3개의 부분으로 되어있습니다: 요청 또는 응답 줄, 해더 부분, 그리고 본문.
클라이언트는 다음과 같이 트랜젝션에 따라 시작합니다:

클라이언트는 서버와 접속하고 문서요청을 보냅니다.

        GET /index.html?param=value HTTP/1.0

다음으로, 클라이언트는 설정과 승인될 문서 구조를 서버에게 알려주기 위하여 임의의 헤더 정보를 보냅니다.

        User-Agent: Mozilla/4.06 Accept: image/gif, image/jpeg, */*

요청과 헤더를 보낸 후, 클라이언트는 아마 추가적인 데이터를 전송할 것입니다. 이 데이터는 대개 CGI 프로그램이 POST 방식으로 사용하는 형식으로 이용됩니다.

학습 목표:

입력필드에 이름을 입력하고 전송을 하기 위해 "go" 버튼을 누릅니다. 서버는 요청을 수락하고, 입력값을 거꾸로 하며, 사용자에게 재출력함으로써 HTTP 요청 처리의 기본을 보여줄 것입니다.

사용자는 버튼을 조작하여 힌트를 보고, HTTP 요청 매개변수와 HTTP 요청 쿠키값, 그리고 자바소스 코드를 보면서 WebGoat의 특징을 잘 알 수 있게 할 수 있습니다.
